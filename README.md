# Architecture and Clean Code Core Notes

An interactive React reference for software architecture, clean code, design principles, code quality, scalability, testing, and maintainability.

![Architecture and Clean Code Core Notes screenshot](./screenshot.jpg)

## Features

- Dedicated lazy-loaded route for every topic
- Searchable sidebar with active-link highlighting
- Responsive mobile navigation drawer
- Light and dark themes with saved preference
- Practical examples, checklists, and engineering notes
- Scroll-to-top control and independent content navigation
- Responsive, keyboard-friendly interface

## Tech Stack

React, React Router, Vite, JavaScript, React Icons, and CSS Modules.

## Getting Started

```bash
npm install
npm run dev
```

Run production checks:

```bash
npm run lint
npm run build
```

## Deployment

Live project: [https://a2rp.github.io/architecture-and-clean-code-core-notes/](https://a2rp.github.io/architecture-and-clean-code-core-notes/)

Deploy to GitHub Pages:

```bash
npm run deploy
```
